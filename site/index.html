How it works

From push to shared in three steps

Three steps, and the second one is a drag.

  1. Push your code

    A push to main deploys production. A pull request gets its own preview address, and the preview goes away when the pull request closes.

  2. Drag it into a circle

    Circles hold people, email domains, devices and networks. A card inside a circle is shared with it.

  3. Your friends open it

    kitshn turns the map into Cloudflare Access, so only the people in the circle get in.

Sharing

Share with people, not passwords

Each circle is a group: a few friends by email, your family, your own phone, or everyone. Circles overlap freely. A card counts for every circle that it sits in.

  • A circle can ask for a passkey after the login.
  • The Owner circle always does, and it holds the kitshn admin card.
  • Change the level for one circle, or set an end date: a share for a guest can end after a week.
Preview

See who gets in before you let go

While you drag a card, every circle edge lights up and a label says what changes, such as + Her · view. The drop applies it.

  • A toast offers Undo, and History keeps every change.
  • A card that enters a public circle asks first.
  • The map works on a phone too. One finger pans, a long press opens the menu, and two fingers zoom.

Self-hosting

Your home server, on the internet, with no open ports

A small daemon joins each machine with one command. It runs the tunnel, deploys Compose apps in rootless Docker, and shares local dev servers as live sites.

  • No open ports: every machine talks through its tunnel.
  • When a machine is off, visitors get this page instead of an error. It costs a Worker request only while the site is down.
Safety

No keys to copy, no secrets to leak

GitHub signs each run with an OIDC token, and kitshn trusts only the GitHub accounts on its list. kitshn never runs the recipe. It reads it as data.

Start

Set it up in one command

You need a free Cloudflare account with a domain, and a GitHub account.

All install steps 
curl -fsSL https://kit.yarden-zamir.com/install | \
  CLOUDFLARE_API_TOKEN=... \
  KITSHN_HOST=kit.example.com \
  KITSHN_OWNER_EMAILS=you@example.com \
  KITSHN_DEPLOY_OWNERS=your-github-name sh
